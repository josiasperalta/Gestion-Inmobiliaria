## 📋 Descripción

Aplicación de escritorio robusta diseñada para optimizar la gestión de inmobiliarias, permitiendo el control completo de propiedades en alquiler y venta, administración de clientes, propietarios y contratos.

## ✨ Características Principales

- 🏠 **Gestión de Propiedades**: Alta, baja, modificación y consulta de inmuebles
- 👥 **Administración de Clientes**: Control de clientes y propietarios
- 📄 **Gestión de Contratos**: Creación y seguimiento de contratos de alquiler/venta
- - 🔍 **Búsqueda Avanzada**: Filtros múltiples para encontrar propiedades
